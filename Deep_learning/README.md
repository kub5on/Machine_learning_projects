## Deep Learning Projects Repository

This repository contains multiple deep learning projects covering computer vision, anomaly detection, time series prediction, and more. Each project is self-contained with its own dataset, training scripts, and README.

---

### Projects Overview

| Project Folder               | Description                                                                 |
|-------------------------------|-----------------------------------------------------------------------------|
| **Cancer_detection**          | Detects cancerous cells in medical images using deep learning models.       |
| **Image_recognition**         | Classifies images into categories using convolutional neural networks.      |
| **Payment_anomalies**         | Detects anomalies in credit card transactions using autoencoder-based models. |
| **Seedling_classification**   | Classifies plant seedlings using MobileNetV2 with FastAPI and Streamlit.   |
| **Stock_prices**              | Predicts stock prices using deep learning and time series models.          |
| **Toxic_content_detection**   | Detects toxic content in text using NLP models and deep learning.           |

---

### General Features

- Implemented using **Python** and **TensorFlow/Keras**.  
- Data preprocessing and augmentation techniques applied where applicable.  
- Models include CNNs, autoencoders, and other architectures depending on the project.  
- Some projects include **REST API** endpoints for predictions (FastAPI).  
- Some projects include **interactive frontends** (Streamlit) for easy testing.
