## Deep Learning Projects Repository 🧠

This repository contains multiple deep learning projects covering computer vision, anomaly detection, time series prediction, and more. Each project is self-contained with its own dataset, training scripts, and README.

### Projects Overview
**Cancer detection:** Detects breast cancer in medical data, classifying tumors as malignant or benign using a neural network.
**Image recognition:** Classifies Fashion MNIST images into 10 categories using a CNN with hyperparameter tuning for optimized performance.
**Payment anomalies:** Detects unusual credit card transactions using an autoencoder to flag potential fraud based on reconstruction errors.
**Seedling classification:** Classifies plant seedlings using MobileNetV2, with FastAPI for predictions and a Streamlit interface for easy interaction.
**Stock prices:** Predicts S&P 500 stock prices using LSTM and GRU models with hyperparameter tuning for optimized forecasting.
**Toxic content detection:** Detects multiple types of toxic comments using a fine-tuned BERT model for multi-label classification.

### General Features
- Implemented using **Python** and **TensorFlow/Keras**.  
- Data preprocessing and augmentation techniques applied where applicable.  
- Models include CNNs, autoencoders, and other architectures depending on the project.  
- Some projects include **REST API** endpoints for predictions (FastAPI).  
- Some projects include **interactive frontends** (Streamlit) for easy testing.
